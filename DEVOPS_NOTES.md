# DEVOPS_NOTES.md

## Статус
Проект полностью готов к деплою на удалённый сервер (VPS). Локально запуск ограничен средой (WSL/Docker Desktop), но вся инфраструктура реализована в виде кода.

## Что настроено

- **Gunicorn**: Запускается через `CMD` в `Dockerfile`. `runserver` удалён.
- **Nginx**: Добавлен как reverse proxy в `docker-compose.yml`. Конфиг — `nginx.conf`.
- **Безопасность**:
  - Пароли вынесены в `.env` (не в git).
  - База данных (`db`) не пробрасывает порты наружу — доступна только внутри сети Docker.
  - Авто-перезапуск: `restart: always` для всех сервисов.
- **Зависимости**: `requirements.txt` содержит все пакеты, включая `gunicorn`.
- **CI/CD**: Подготовлен шаблон workflow для GitHub Actions.

## План запуска на сервере (VPS)

1. Арендовать любой VPS (Ubuntu 22.04), получить IP.
2. Зайти по SSH, установить Docker.
3. Клонировать репозиторий, создать `.env` из шаблона, вставить IP в `ALLOWED_HOSTS`.
4. Запустить: `docker compose up -d --build`.
5. Применить миграции: `docker compose exec web python manage.py migrate`.
6. Собрать статику: `docker compose exec web python manage.py collectstatic --noinput`.
7. Приложение будет доступно по IP сервера на порту 80 (через Nginx).

## Критерии задания

| Критерий | Статус | Комментарий |
|----------|--------|-------------|
| Gunicorn + Nginx настроены | ✅ | В конфигах и Dockerfile |
| Порты закрыты корректно | ✅ | У `db` нет `ports`, только внутренняя сеть |
| Авто-перезапуск | ✅ | `restart: always` везде |
| Приватные данные вынесены | ✅ | Пароли только в `.env` |
| `.env.template` полный | ✅ | Содержит все переменные |
| Workflow готов | ✅ | Шаблон в `.github/workflows/` |
| IP-доступ | ⚠️ | Требует реальный VPS. Логика готова. |
